
# Sales Forecasting & Inventory Intelligence

## About the Project
This project analyzes historical sales data to forecast future sales and provide inventory-related insights.

## Features
- Exploratory Data Analysis (EDA)
- Sales trend visualization
- Sales forecasting using machine learning
- Model performance comparison
- Inventory status analysis
- Interactive Streamlit dashboard
- CSV download functionality

## Machine Learning Models
- Seasonal Naive Baseline
- Random Forest Regressor
- Gradient Boosting Regressor

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit
- Joblib
- Google Colab

## Dataset
Store Sales - Time Series Forecasting dataset from Kaggle.

https://www.kaggle.com/competitions/store-sales-time-series-forecasting

## How to Run
1. Install the required libraries:
   `pip install -r requirements.txt`

2. Run the Streamlit application:
   `streamlit run app.py`

## Limitations
Inventory recommendations use demo assumptions because actual stock-on-hand data is not available in the dataset.
